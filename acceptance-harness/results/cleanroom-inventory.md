# Danh mục kiểm tra Clean-Room (Blind Inventory) — Hệ thống Đề thi V-SAT

- **Phạm vi**: Backend API thêm/sửa/duyệt/phát hành đề thi, ngân hàng câu hỏi, ma trận blueprint, import, xuất bundle học sinh và chấm điểm V-SAT.
- **Cách lấy token & query DB**:
  - Đăng nhập lấy Bearer token qua `POST /api/v1/auth/login` với tài khoản chuẩn theo role: `SUPER_ADMIN` (`superadmin@vsat.com`), `CONTENT_ADMIN` (`contentadmin@vsat.com`), `COLLABORATOR` (`collab@vsat.com`), `STUDENT` (`student@vsat.com`).
  - Đối chiếu DB local qua `psql` trên database `vsat_compass_acceptance` (container `vsat-clean-pg`).
- **Quy ước đường dẫn**: Toàn bộ path bên dưới tính sau base `/api/v1` (theo cơ chế `apiCall` của harness).

## Ngoài khả năng tự động

Các hạng mục sau cần **mắt người** hoặc **thiết bị thật**, không thể nghiệm thu hoàn toàn bằng probe API đơn thuần:

1. **Hiển thị công thức Toán / Hóa / Lý (LaTeX/MathJax/WebView) & hình ảnh**: Kiểm tra trực quan trên màn hình Android và trình duyệt web admin xem `questionHtml`, `optionHtml`, ảnh minh họa có bị cắt chữ, lệch dòng hay lỗi font tiếng Việt không.
2. **Trải nghiệm tương tác kéo-thả / chọn cặp câu Ghép hợp (`MATCHING`) và nhập đáp án `SHORT_ANSWER`**: Cần thao tác chạm tay trên màn hình cảm ứng thiết bị Android kích thước nhỏ (320dp–360dp) để xác nhận không che khuất bàn phím ảo và dễ chọn cặp.
3. **Phát audio thực tế & chống gian lận ở mức thiết bị (`LockTask` / thoát app)**: Cần thiết bị Android thật để xác nhận audio nghe thực sự phát qua loa/tai nghe, không bị giật khi mất mạng (offline bundle) và cơ chế khóa màn hình/bắt sự kiện chuyển ứng dụng hoạt động đúng trên phiên bản Android mục tiêu.
4. **Hành vi giao diện Web Admin Wizard (Step1–Step4 & Import UI)**: Cần trình duyệt (hoặc Playwright kết hợp kiểm tra thị giác) để kiểm tra thông báo lỗi khi API trả 403/500, thứ tự nhãn Part 1–Part 4 trên màn hình, và danh sách dropdown profile chấm điểm thực tế hiển thị cho người biên soạn.
5. **Thẩm định học thuật & đối chiếu đề minh họa Ngữ văn (bài luận ~200 chữ, 30 điểm chấm tay)**: Việc kiểm tra tính đúng đắn nội dung đề thi và chất lượng chấm tay không thể tự động hóa bằng API backend.
